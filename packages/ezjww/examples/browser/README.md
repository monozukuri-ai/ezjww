# ezjww browser example

Open a JWW or supported JWC drawing, inspect its source data, preview it, and
save a converted DXF. You can also create and download a new JWW example.
Parsing and writing run locally in WebAssembly.

## Run the example

Use Node.js 22.12+ (or 20.19+ on the 20.x line), Rust, and pnpm. From a repository
checkout:

```bash
cd packages/ezjww
pnpm install
pnpm run example:browser:dev
```

Open the URL printed by Vite. Load the bundled JWW sample, or choose or drop your
own `.jww` or `.jwc` file. For JWC, choose paper or model millimeters and review
the conversion notices before downloading the DXF.

Choose **JWW作成例** to generate a version-700 drawing with a line, circle,
circular arc, point and Japanese text, then preview it with the existing reader.
**生成JWW保存** downloads those generated bytes as `created.jww`; **DXF保存**
exports the preview as DXF. Open the downloaded JWW again to inspect it. The JWW
save button is available only for the generated example. Existing input files
are not editable by the writer.

The example calls raw web-target WASM `newJwwDocument()` / `toJwwBytes()` after
`initWasm()`. Its typed input uses `JwwWriteDocument`; angles for native arc
fields are radians, while text angles are degrees. See the
[writer guide](../../../../docs/JWW_WRITE.md) for input fields and support limits.

## Build and preview

From `packages/ezjww`:

```bash
pnpm run example:browser:build
pnpm run example:browser:preview
```

## Display limits

JWC support is limited to the [supported binary profile](../../../../docs/JWC_FORMAT.md).
Invisible JWC layers are hidden. JWC text uses substitute fonts; exact source
glyphs and character spacing are not reproduced. JWW text is shown as insertion
markers in the preview; use the source JSON or downloaded file to inspect its
content. The source JWC version is unknown.

See the [API reference](../../../../docs/JWC_API.md) for coordinate options,
source records, and diagnostics.
